# 회귀 테스트

전체 화면과 핵심 로직을 브라우저에서 자동 검증합니다.

## 실행

```bash
# 1) 로컬 서버 (저장소 루트에서)
python -m http.server 9090

# 2) 다른 터미널에서
pip install playwright
playwright install chromium
python scripts/regression-v6.py
```

## 검사 항목 (58건)

| 그룹 | 내용 |
|---|---|
| 기본 로드 | 페이지 오류, 메뉴 197개, 레시피·delivery 연결 |
| 패널 순회 | 9개 패널 전환 |
| 추천 알고리즘 | 576개 조합에서 결과 0개가 없는지 |
| 5단계 질문 | 상황→종류→입맛→예산→방식 완주 |
| 결정 후 | 배너 표시, 버튼, 새 추천 시 초기화 |
| 메뉴 상세 | 검색→상세 이동, 데이터 채움, 뒤로 복귀 |
| 레시피 | 통계칩, 재료, N단계 동적 제목, 요리 모드 |
| 주변 식당 | 시트 구조, 순위, 지도 폴백, 안내 제거 확인 |
| 좌표 보존 | formatPlace가 lat/lng를 버리지 않는지 |
| 그룹 투표 | 만들기 화면, 목업 잔재 없음 |
| 전역 API | 10개 함수 노출 확인 |
