# 오늘의 식탁 v4.8 릴리스 노트

## 목적

친구 베타에서 확인된 기록 진입 문제, 음식 탐색 부재, 추천 카테고리 부족, 내 입맛 필터 불일치를 수정합니다.

## 변경 사항

1. 기록 탭에서 추천 과정 없이 음식 이름을 검색하거나 직접 입력해 저장할 수 있습니다.
2. 기존 찜 탭을 음식 탐색 탭으로 확장해 메뉴 검색, 음식 종류 필터, 상세정보, 찜을 한 흐름으로 연결했습니다.
3. 추천 질문에 음식 종류 단계를 추가해 한식·중식·일식·양식·세계음식을 직접 선택할 수 있습니다.
4. 내 입맛에서 선택한 음식 종류는 추천 질문에서 별도 종류를 고르지 않은 경우 기본 허용 범위로 적용합니다.
5. 다이어트 조건은 600kcal 이하이면서 튀김·디저트·베이커리성 메뉴가 아닌 후보만 허용합니다.
6. 직접 입력한 메뉴는 스냅샷으로 저장해 앱 재실행 후에도 기록이 사라지지 않습니다.

## 회귀 검증

- 일식 + 다이어트 프로필에서 다른 음식 종류가 후보에 포함되지 않아야 합니다.
- 스콘은 다이어트 후보에서 제외되어야 합니다.
- 추천 질문은 4단계이며 음식 종류 단계가 포함되어야 합니다.
- 기록 모달은 currentMenu 없이도 열리고 직접 입력 메뉴를 저장할 수 있어야 합니다.
