# 메뉴 데이터 정책

## 원칙

이 프로젝트는 추천 후보를 만들 때 가짜 메뉴를 자동 생성하지 않습니다.

- 허용: `미역국`, `소고기 미역국`, `성게 미역국`, `들깨 미역국`
- 금지: `미역국 전문점2`, `미역국 간편식1`, `모닝 라이트 미역국`, `홈쿡3`

## 추천 정책

1. 추천 후보는 `data/menus.json`에 직접 등록된 메뉴만 사용합니다.
2. 조건 조합에 후보가 0개여도 자동으로 메뉴명을 만들어내지 않습니다.
3. 후보가 부족하면 사용자가 조건을 완화하거나, 개발자가 실제 메뉴명을 조사해 DB에 추가해야 합니다.
4. `data/recipes.json`에는 `data/menus.json`과 같은 실제 메뉴명만 키로 등록합니다.

## 메뉴 추가 절차

1. 실제로 존재하는 음식명인지 확인합니다.
2. 국가/음식 계열을 확인합니다.
3. `type`, `time`, `weight`, `soup`, `spicy`, `method`를 실제 음식 성격에 맞게 입력합니다.
4. 레시피가 필요한 메뉴는 `data/recipes.json`에 출처 기반 초보자용 레시피를 추가합니다.
5. 지도 검색 키워드는 `data/restaurant-keywords.json`에 추가합니다.
