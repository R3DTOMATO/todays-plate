# 오늘의 식탁 한국 베타 v4.4 릴리스 노트

## 수정 목적

친구 베타에서 다음 문제가 확인되었습니다.

- 집밥을 골라도 한식보다 양식·세계음식이 지나치게 자주 노출됨
- 부리또를 넘긴 직후 아침 부리또가 다시 추천됨
- 볼로네제와 라구 파스타처럼 사실상 같은 음식 계열이 연속 노출됨
- 현재 식사 시간과 맞지 않는 아침 전용 메뉴가 다른 시간대에 노출됨
- 99점 상한으로 여러 메뉴가 동점이 되어 실제 점수보다 가나다순이 추천 순위에 영향을 줌

## 핵심 변경

### 1. 메뉴 계열 단위 리롤

모든 메뉴에 `family` 필드를 추가했습니다.

- 부리또 / 아침 부리또 → `burrito`
- 볼로네제 / 라구 파스타 → `ragu-pasta`
- 미역국 변형, 볶음밥 변형, 파스타 변형 등 유사 메뉴 계열을 묶음

사용자가 메뉴를 넘기면 해당 메뉴 이름뿐 아니라 같은 계열 전체를 현재 추천 세션에서 제외합니다.

### 2. 한국형 집밥 우선순위

모든 메뉴에 다음 메타데이터를 추가했습니다.

- `homeSuitability`: `common`, `possible`, `special`, `outside`
- `familiarity`: `common`, `familiar`, `explore`

집밥에서는 다음 순서로 점수를 조정합니다.

1. 일상적으로 집에서 만들기 쉬운 메뉴 우선
2. 조리시간 30분 이하 우선
3. 한식과 한국에서 익숙한 일식·중식 우선
4. 45분 이상 정성 요리와 생소한 세계음식 감점

### 3. 시간대 일관성

- 현재 시간대와 같은 메뉴의 점수를 강화
- 현재 시간이 아침이 아니면 아침 전용 메뉴를 후보에서 제외
- 아침 부리또, 아침 머핀, 에그 베네딕트 등 시간대가 명확한 메뉴가 저녁 리롤에 나오지 않음

### 4. 답변 의도 강화

- `가볍게`, `든든하게`, `해장·국물`, `매콤하게` 선택이 대표 메뉴 순위에 더 강하게 반영됨
- 매콤하게 선택했을 때 대표 메뉴가 실제 매운 메뉴인지 자동 검증

### 5. 결과 다양성

대표 메뉴와 대안 메뉴 최대 2개를 고를 때 같은 `family`가 중복되지 않습니다.
점수 차가 크지 않으면 대안 중 하나는 다른 음식 종류를 우선합니다.

### 6. 정렬 점수 동점 문제 수정

내부 추천 점수의 99점 상한을 제거했습니다.
화면 표시는 최대 99%로 유지하지만, 내부 정렬은 원점수를 사용해 가나다순 동점 문제를 줄였습니다.

## 데이터 변경

- 메뉴 수: 197개
- 음식 계열: 161개
- 일반 집밥 우선 메뉴: 47개
- 모든 메뉴에 `family`, `homeSuitability`, `familiarity` 필드 추가

## 검증

`npm run validate:recommendation`으로 다음을 검사합니다.

- 메뉴 메타데이터 누락 여부
- 부리또 및 라구 계열 연결 여부
- 집밥 대표 메뉴의 한식 우선 여부
- 16개 시간대·식사욕구 조합의 대표 메뉴 적합성
- 결과 3개 내 같은 음식 계열 중복 여부
- 아침 외 시간대의 아침 전용 메뉴 차단
- 부리또 리롤 후 부리또 계열 전체 제외
