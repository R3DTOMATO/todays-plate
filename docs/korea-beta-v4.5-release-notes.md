# 오늘의 식탁 한국 베타 v4.5

## 집밥 기준 국가
- 집밥은 사용자의 국가/생활권 음식 문화를 기준으로 합니다.
- 대한민국은 한식, 일본은 일식, 중국·대만·홍콩은 중식을 대표 집밥으로 우선합니다.
- 입맛 설정에서 국가를 직접 변경할 수 있습니다.
- 집밥 대표 메뉴는 해당 국가 음식으로 고정하고 대안에서 다른 음식 문화를 허용합니다.

## 주변 식당 검색
- 메뉴명을 다른 유행 음식으로 치환하지 않습니다.
- 라조기는 `라조기`로 먼저 검색하며, 일반 중식 메뉴를 `마라`로 확장하지 않습니다.
- 정확 메뉴 검색 결과가 부족하면 가까운 동일 음식 문화 식당을 후보로 표시합니다.
- Kakao Local API는 전체 메뉴판을 제공하지 않으므로 음식 문화 후보에는 `메뉴 판매 여부 확인`을 표시합니다.
- 라조기·유린기·깐풍기·멘보샤·꿔바로우 등 중식 메뉴 검색어를 보강했습니다.
