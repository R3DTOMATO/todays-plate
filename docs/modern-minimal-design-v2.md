# Today's Plate 모던 미니멀 디자인 v2

참고한 방향은 요즘IT의 「디자인 트렌드, 모던 미니멀 스타일의 UI 가이드」입니다.

## 적용 원칙

1. **밝은 배경과 충분한 여백**
   - 전체 캔버스를 흰색으로 정리하고, 회색은 섹션 구분과 보조 정보에만 사용합니다.
   - 카드 사이 간격을 넓히고 홈에서 핵심 행동이 먼저 보이도록 구성했습니다.

2. **절제된 라운드 처리**
   - 모든 요소를 과도하게 둥글게 만들지 않고, 주요 카드 18~24px, 작은 버튼 12~14px로 계층화했습니다.

3. **크고 읽기 쉬운 제목**
   - 홈과 결과 화면 제목을 크게 유지하되 본문과 명확한 대비를 만들었습니다.
   - 한국어 가독성을 위해 Noto Sans KR을 기본으로 사용합니다.

4. **실제 음식 사진**
   - 홈 히어로와 추천 결과, 후보·찜·기록 카드에 음식 사진을 배치했습니다.
   - 프로토타입에서는 음식 분류별 대표 이미지를 사용합니다. 출시 전 메뉴별 자체 이미지 또는 정식 라이선스 이미지를 확보해야 합니다.

5. **색상 사용 제한**
   - 핵심 강조색은 코랄 한 가지로 제한했습니다.
   - 검정은 중요한 결정 버튼, 회색은 보조 정보에 사용합니다.

6. **대비 중심의 정보 계층**
   - 추천 결과에서 사진 → 메뉴명 → 핵심 정보 → 결정 버튼 순서로 읽히도록 수정했습니다.

7. **효과 최소화**
   - 큰 그라디언트, 강한 그림자, 과도한 글래스 효과를 제거했습니다.
   - 그림자는 하단 내비게이션과 핵심 CTA처럼 깊이가 필요한 요소에만 사용합니다.

8. **작은 디테일**
   - 사진 캡션, 추천 적합도, 섹션 키커 등은 작게 처리해 주 콘텐츠와 경쟁하지 않도록 했습니다.

## 이번 버전에서 변경한 화면

- 홈 히어로를 일러스트 중심에서 실제 음식 사진 중심으로 변경
- 코랄 그라디언트 배경을 흰색 편집형 레이아웃으로 변경
- 주요 CTA에만 강조색 사용
- 결과 카드에 대형 음식 사진 추가
- 후보·찜·오늘 기록·식단 기록에 썸네일 추가
- 메타 정보를 `준비 시간 · 예상 열량 · 한 끼 예산` 3열 구조로 정리
- 데이터 초기화 버튼을 홈에서 내 입맛 화면으로 이동
- 키보드 포커스와 모션 감소 설정 추가

## 주의사항

현재 사진은 프로토타입 확인을 위한 외부 이미지 URL입니다. 실제 서비스에서는 외부 핫링크를 제거하고 다음 중 하나로 전환해야 합니다.

- 직접 촬영한 메뉴 사진
- 정식 라이선스를 구매한 이미지
- 라이선스 조건을 확인한 이미지를 자체 CDN에 저장

메뉴별 사진이 준비되지 않았을 때는 음식 분류별 대표 이미지와 이모지 폴백이 표시됩니다.
