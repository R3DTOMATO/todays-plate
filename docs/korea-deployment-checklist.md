# 한국 공개 배포 전 체크리스트

## P0 · 스토어 심사 전 필수

- [ ] `server/kakao-nearby-proxy.mjs`를 HTTPS 환경에 배포
- [ ] `KAKAO_REST_API_KEY`를 서버 비밀 환경변수로 설정
- [ ] 운영 도메인만 `ALLOWED_ORIGINS`에 등록
- [ ] Firebase Auth 또는 동등한 인증 수단 연결
- [ ] 익명 데이터와 로그인 계정 데이터 병합
- [ ] Firestore 보안 규칙과 데이터 삭제 기능 구현
- [ ] 개인정보처리방침·이용약관·위치 사용 안내 연결
- [ ] 외부 Unsplash 프로토타입 이미지를 정식 라이선스 이미지/CDN으로 교체
- [ ] 로컬 분석 큐를 실제 분석 플랫폼으로 전송
- [ ] 오류 추적과 앱 충돌 모니터링 연결
- [ ] 스토어 스크린샷과 실제 기능 일치 확인

- [ ] 메뉴별 가격과 식당 검색 결과 직접 검수
- [ ] 거절 이유 상위 항목 분석
- [ ] 추천 결과가 3개 미만인 조건 조합 확인
- [ ] Android 주요 기기와 iPhone 소형 화면 검수
- [ ] 저속 네트워크·위치 거부·데이터 로드 실패 테스트
