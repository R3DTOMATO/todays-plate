## 실기기 P0

Android Chrome, iPhone Safari, 카카오톡 인앱 브라우저에서 각각 아래 흐름을 확인한다.

1. 추천 시작 → 음식 종류 → 욕구 → 예산 → 메뉴 결정
2. 다른 메뉴 5회 요청 후 같은 음식 계열 반복 여부
3. 집밥 기준 국가별 대표 음식 확인
4. 음식 탐색에서 `가츠동`, `김치찌개`, `짜장면`, `샤브샤브` 한글 입력
5. 메뉴 상세 → 찜 → 레시피 → 주변 식당 → 식사 기록
6. 기록 사진 첨부 → 저장 → 수정 → 사진 제거 → 삭제
7. 위치 허용, 위치 거부, 지역 직접 입력
8. 오프라인 전환 후 기록과 피드백 보관
9. 앱 종료 후 다시 열었을 때 기록·찜·최근 검색 복원
10. 내 입맛에서 버전·API·Kakao 연결 상태 확인

## 주변 식당 검증

김치찌개, 라조기, 가츠동, 바베큐 립, 파스타, 쌀국수, 초밥, 샤브샤브를 서로 다른 3개 지역에서 확인한다.

- 정확 메뉴 검색 결과와 전문점 후보가 구분되는가
- 카페·커피 전문점 등 무관 업종이 제외되는가
- 메뉴를 다른 음식으로 임의 치환하지 않는가
- 3km, 7km, 12km, 20km 확장이 정상인가
- 결과가 없을 때 판매 여부를 단정하지 않는가

## 출시 중단 조건

아래 중 하나라도 발생하면 와디즈 공개를 중단한다.

- 빈 화면 또는 탭 무반응
- 알레르기·제외 재료 위반
- 선택한 음식 종류와 다른 종류 추천
- 기록 저장·수정 후 데이터 유실
- 사진 때문에 전체 기록 저장 실패
- 주변 식당 검색에서 명백히 무관한 업종 반복 노출
- API 키 또는 `.env`가 저장소에 노출
