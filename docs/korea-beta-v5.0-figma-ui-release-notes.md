# 오늘의 식탁 v5.0 Figma UI/UX 적용

## 기준 디자인

- Figma 파일: `오늘의 식탁 — Award UI/UX`
- 구현 화면: Home, Occasion, Preferences, Result, Nearby, Group Vote, History, My Taste, Loading, Location Denied, Empty, Error
- 주요 토큰: `#FFFAF7` 캔버스, `#C93F31` 브랜드, `#201A17` 기본 글자, `#7D6F68` 보조 글자, 16/20/24px 모서리

## 기능 변화

- 기존 4개 추천 질문을 두 입력 화면과 한 결과 단계로 축소했습니다.
- 첫 화면에서 식사 상황을 고르고, 다음 화면에서 음식 성향 최대 두 개와 1인 예산을 함께 선택합니다.
- 회식·팀프로젝트·가족·데이트 상황은 후보 제거 조건이 아니라 추천 점수 신호로 사용합니다.
- 그룹 투표 화면은 UI와 이 기기의 임시 선택 저장까지만 제공합니다. 공유 링크와 실시간 동기화는 서버 연결이 필요한 후속 범위입니다.

## 유지한 기능

- 메뉴 197개와 한국형 추천·익숙한 메뉴 우선 로직
- 메뉴 검색·찜·최근 검색·최근 본 음식
- 위치 권한 또는 직접 지역 입력 기반 주변 식당 검색
- 레시피, 식사 기록, 사진 압축, 기록 수정·삭제
- 분석 동의, 피드백 큐, 앱 상태와 오류 코드
