# Recipe QA Policy

## 목적
레시피 화면에 표시되는 모든 조리법이 `data/recipes.json`의 검증 데이터에서만 나오도록 관리한다. 앱은 없는 레시피를 자동 생성하지 않는다.

## QA 통과 기준
각 메뉴 레시피는 최소한 아래 조건을 만족해야 한다.

1. `verified: true`
2. `sourceBasis` 1개 이상
3. 확인 가능한 URL 출처 1개 이상
4. 재료 3개 이상
5. 초보자용 조리 단계 5단계 이상
6. 필요한 도구 1개 이상
7. 완성 확인 기준 2개 이상
8. 실패 포인트 2개 이상
9. `주재료`, `물 또는 육수`, `마늘/대파`, `generic`, `템플릿` 같은 범용 템플릿 표현이 없어야 함

## QA 화면 사용법
앱 하단의 `QA` 탭에서 전체 메뉴의 레시피 품질을 검사한다.

- 검색: 메뉴명, 출처명, 재료명으로 검색
- 음식 종류: 한식/중식/일식/양식/세계음식 필터
- 상태: 수정 필요 / 보완 필요 / 통과 필터
- QA 리포트 저장: 현재 검사 결과를 JSON으로 다운로드

## 수정 원칙
`수정 필요` 메뉴는 앱 코드에서 보정하지 말고 `data/recipes.json`을 직접 수정한다. 레시피 문장은 원문을 복사하지 않고 조리 원리만 확인한 뒤 초보자용 문장으로 재작성한다.
