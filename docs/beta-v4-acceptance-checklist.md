# 친구 베타 v4 승인 체크리스트

## 추천

- [ ] 로그인 없이 홈에서 추천을 시작할 수 있다.
- [ ] 식사 방식, 원하는 식사, 예산 세 단계를 완료할 수 있다.
- [ ] 현재 시간이 아침·점심·저녁·야식으로 올바르게 표시된다.
- [ ] 앱을 닫고 다시 열었을 때 진행 중 추천을 이어갈 수 있다.
- [ ] 최근 3일 내 기록한 같은 메뉴가 다시 나오지 않는다.
- [ ] 방금 거절한 메뉴가 같은 세션에서 다시 나오지 않는다.
- [ ] 후보가 없을 때 조건을 몰래 완화하지 않고 수정 방법을 안내한다.
- [ ] 대표 메뉴와 대안 메뉴가 합계 최대 세 개다.

## 제한 조건과 결과 정보

- [ ] 알레르기 식재료가 포함된 메뉴는 후보에서 제외된다.
- [ ] 먹지 않는 식재료가 포함된 메뉴는 후보에서 제외된다.
- [ ] 예산 상한보다 비싼 메뉴가 나오지 않는다.
- [ ] 결과에 가격, 시간, 방식, 재료, 매운맛, 포만감, 알레르기 후보가 표시된다.
- [ ] 교차 오염 직접 확인 안내가 보인다.

## 거절과 기록

- [ ] 9개 거절 이유와 이유 없이 다시 추천이 작동한다.
- [ ] 양·조리 부담 피드백이 다음 후보 순위에 반영된다.
- [ ] 식사 날짜, 방식, 금액, 만족도, 재선택, 메모, 사진을 저장할 수 있다.
- [ ] 기록 저장 실패 시 입력값이 사라지지 않는다.
- [ ] 신규 사용자에게 임의의 식사 기록이 보이지 않는다.
- [ ] 기록을 삭제할 수 있다.

## 위치와 식당

- [ ] 주변 식당 버튼을 누르기 전에는 위치 권한을 요청하지 않는다.
- [ ] 권한 요청 전 목적과 비추적 안내가 표시된다.
- [ ] 권한 거부 후 지역·주소·역 이름을 입력할 수 있다.
- [ ] 결과 없음, 네트워크 실패, API 오류 상태가 구분된다.
- [ ] 식당 선택 이벤트가 기록된다.
- [ ] 브라우저 코드에 Kakao REST API 키가 없다.

## 분석·개인정보·피드백

- [ ] 분석 동의 전에는 이벤트가 생성되지 않는다.
- [ ] 동의를 거부해도 추천과 기록을 사용할 수 있다.
- [ ] 동의를 철회하면 로컬 분석 큐가 삭제된다.
- [ ] 이벤트에 정밀 위치, 주소, 연락처, 메모, 사진이 포함되지 않는다.
- [ ] 오프라인 이벤트와 피드백이 온라인 복구 후 전송된다.
- [ ] 내 데이터를 JSON으로 내려받을 수 있다.
- [ ] 전체 로컬 데이터를 초기화할 수 있다.
- [ ] 서버 리포트가 추천 퍼널과 거절 이유를 출력한다.

## 배포 전 실기기

- [ ] Android Chrome에서 위치 권한 허용·거부를 모두 테스트했다.
- [ ] iPhone Safari에서 위치 권한 허용·거부를 모두 테스트했다.
- [ ] 사진 선택과 로컬 저장 용량 한계를 테스트했다.
- [ ] 느린 네트워크와 오프라인 전환을 테스트했다.
- [ ] 동일 버튼 연속 입력으로 중복 기록이 생기지 않는다.
