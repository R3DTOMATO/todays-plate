# 오늘의 식탁 브랜드 에셋

## 핵심 심볼

- 파일: `assets/brand/logo-symbol.svg`
- 의미: 식사 결정을 상징하는 클로슈, 식탁을 나타내는 포크와 숟가락, 신선함을 나타내는 잎
- 작은 크기에서 인식되도록 얇은 세부 묘사와 문자를 넣지 않았습니다.

## 색상

| 용도 | 색상 |
|---|---|
| 메인 코랄 | `#FF684E` |
| 보조 그린 | `#19B78D` |
| 차콜 | `#34363A` |
| 배경 | `#FFFFFF` |

## 제공 파일

- `assets/brand/logo-symbol.svg`

- `assets/icons/favicon-32.png`

## 사용 규칙

- 아이콘 주변에는 심볼 높이의 약 15% 이상 여백을 유지합니다.
- 아이콘 내부 요소의 색상을 임의로 여러 색으로 바꾸지 않습니다.
- 음식 사진 위에 직접 배치할 때는 흰색 단색 배경을 함께 사용합니다.
- 작은 앱 아이콘에는 서비스명이나 슬로건을 넣지 않습니다.
