# 오늘의 식탁 와디즈 펀딩 진입 체크리스트

## 펀딩 전 제품 기준

- [ ] v4.4 추천 회귀 테스트 통과
- [ ] 친구 5명 이상이 각 3회 이상 추천 실행
- [ ] 집밥 선택 시 생소한 메뉴가 과도하게 나온다는 피드백 해소
- [ ] 같은 음식 계열 연속 추천 0건
- [ ] 위치 허용·거부·직접 지역 입력 모두 정상
- [ ] 식사 기록 저장 후 재실행해도 유지
- [ ] 모바일 Chrome·Safari에서 주요 버튼 가림 없음
- [ ] 개인정보 처리 안내와 데이터 삭제 기능 확인
- [ ] Kakao API 키와 `.env`가 GitHub에 노출되지 않음

## 펀딩 페이지 핵심 메시지

> 오늘 뭐 먹지 고민하는 시간을 줄이고, 실제 한 끼 결정까지 연결하는 음식 의사결정 앱

강조할 내용:

1. 3개의 질문으로 메뉴 결정
2. 마음에 들지 않는 이유를 반영해 다음 추천 개선
3. 최근 먹은 메뉴와 같은 계열 반복 방지
4. 주변 식당·레시피·식사 기록까지 연결
5. 한국인의 실제 집밥 감각을 반영한 추천

## 펀딩 전 확보할 증거

- 실제 화면 녹화 30~45초
- 친구 베타 전후 추천 사례
- 대표 피드백 5개 이상
- 추천 시작 → 결과 → 결정 흐름의 수치
- 메뉴 리롤 전후 개선 사례
- 베타 사용자의 동의를 받은 후기와 캡처

## 오픈 판단

다음 조건을 모두 충족해야 오픈예정 페이지를 공개합니다.

- 치명적 오류 0건
- 추천 결과가 이상하다는 동일 유형 피드백이 반복되지 않음
- 최소 15개 실제 추천 세션 검증
- 리워드 제공 범위와 제공일 확정
- 펀딩금을 어디에 사용할지 항목별 예산 확정
