# 오늘의 식탁 v5.1 Figma 프레임 정합성 개선

## 변경 사항

- 홈을 Figma 393px 캔버스 기준으로 고정해 제목과 빠른 결정 카드가 한 줄에 배치되지 않도록 수정했습니다.
- 홈에서 피그마에 없는 `바로 추천`, `내 입맛 설정`, 오늘의 식사 기록, 찜 바로가기, 추천 이어하기 영역을 제거했습니다.
- 빠른 결정의 상황 선택은 선택 직후 다음 화면으로 넘기지 않고, Figma처럼 선택 상태와 안내 카드를 보여준 뒤 다음으로 진행합니다.
- 결과 화면을 1순위 메뉴 카드, `이 메뉴로 결정`, `다시 추천`, `저장하기`만 남기는 구조로 단순화했습니다.
- CSS·JS 캐시 버전을 `5.1.0`으로 올려 이전 레이아웃이 남지 않도록 했습니다.

## 유지 범위

- 메뉴 197개 추천 데이터와 한식 우선·예산·상황 반영 로직
- 주변 식당, 음식 탐색, 식사 기록, 내 입맛 탭
- Railway 기반 주변 식당 API 설정
