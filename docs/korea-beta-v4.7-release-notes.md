# 오늘의 식탁 v4.7 한식 비중·예산 구간 개선

## 문제

친구 베타에서 다음 문제가 확인되었습니다.

- 음식 종류를 고르지 않으면 생소한 양식·세계음식이 대표 결과에 자주 노출됨
- 한국 사용자에게 한식이 기본값처럼 느껴지지 않음
- 예산 선택지가 7천원·1만원·1만5천원·무제한으로 촘촘하면서도 고가 구간이 부족함
- 메뉴 평균 가격을 선택 금액으로 딱 잘라 후보에서 제외해 실제 가격 변동을 반영하지 못함

## 변경

### 시장 기본 음식

- 국가 설정이 대한민국이고 음식 종류를 직접 선택하지 않은 경우 한식에 기본 가중치를 부여합니다.
- 결과 3개는 가능한 경우 한식 2개와 익숙한 다른 음식 1개로 구성합니다.
- `explore`로 분류된 생소한 메뉴는 익숙한 후보가 3개 이상 있을 때 기본 결과에서 제외합니다.
- 사용자가 입맛 설정에서 음식 종류를 선택하면 그 선택이 국가 기본값보다 우선합니다.

### 예산

- 약 1만원: 최대 1만2천원 정도
- 약 3만원: 최대 3만3천원 정도
- 약 5만원: 최대 5만5천원 정도
- 가격 상관없음

가격은 지역과 매장에 따라 달라지므로 표시 금액은 목표 예산, 내부 상한은 소폭 확장된 범위로 사용합니다.

## 호환성

기존 저장값은 다음과 같이 자동 이동합니다.

- 7천원·1만원 → 약 1만원
- 1만5천원·2만5천원 → 약 3만원
- 5만원 이하 → 약 5만원
