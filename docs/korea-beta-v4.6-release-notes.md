# 오늘의 식탁 v4.6 주변 식당 검색 수정

## 수정한 문제

- 바베큐 립 검색이 브런치 카페로 확장되던 문제
- 메뉴와 무관한 카페를 높은 추천도로 표시하던 문제
- 카카오 키워드 검색 결과를 메뉴 판매 확인으로 오해하던 문제
- Firebase 배포 후 오래된 app.js가 남을 수 있는 캐시 문제

## 검색 정책

1. 정확 메뉴명과 표기 변형 검색
2. 메뉴에 맞는 전문 업종 검색
3. 상호명 일치, 메뉴 검색 후보, 전문점 후보를 구분
4. 판매가 확인되지 않은 장소에는 추천도 표현을 사용하지 않음
5. 일반 식사 메뉴에서는 카페·커피·디저트 업종 제외

## 바베큐 립 예시

- 바베큐 립
- 바비큐 립
- BBQ 립
- 폭립
- 바베큐 폭립
- 미국식 바비큐
- 스테이크하우스
- 그릴 레스토랑

`브런치`는 검색하지 않습니다.
