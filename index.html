기기에만 저장되는 정보

찜, 식사 기록, 음식 사진과 메모는 현재 브라우저에 저장됩니다. 사진은 최대 1280px로 압축되며 피드 공개를 선택한 경우 업로드됩니다. 입맛 설문은 계정별 비공개 문서에 저장되고 다음 로그인에서 불러옵니다. 브라우저 데이터나 앱 저장 공간을 삭제하면 복구되지 않을 수 있으므로 필요한 경우 데이터 파일을 내려받아 보관하세요.

위치 정보

주변 식당 찾기를 누른 시점에만 위치를 요청합니다. 좌표는 Railway 서버를 거쳐 Kakao 장소 검색에 일시적으로 사용되며 이벤트 파일에는 저장하지 않습니다. 권한을 거부하면 지역·주소·역 이름을 직접 입력할 수 있습니다.

서버로 전송되는 정보

분석에 동의한 경우 익명 사용자 ID, 세션 ID, 추천 단계, 선택·거절, 기능 이용과 오류 코드가 전송됩니다. 의견 보내기에서는 사용자가 입력한 내용과 선택적으로 입력한 연락처가 전송됩니다. 정밀 위치, 음식 사진, 식사 메모 원문은 분석 이벤트에 포함하지 않습니다.

보관과 삭제

베타 이벤트와 피드백은 운영 서버에서 원칙적으로 90일 동안 보관합니다. 분석 동의는 언제든 끌 수 있고, 기기 데이터는 ‘모든 앱 데이터 초기화’로 삭제할 수 있습니다. 서버 데이터 삭제 요청은 아래 버튼으로 접수하세요.
